# 데브스펙트럼 삼각성향검사 가이드

본 문서는 AoID 플랫폼의 데브스펙트럼(DevSpectrum) 서비스 중 하나인 **삼각성향검사(Triangle Test)**의 검사 방식, 질문 작성 요령, 채점 메커니즘 및 결과지 설정 방법에 대해 설명하는 통합 가이드라인입니다.

---

## 1. 검사 개요 및 원리

삼각성향검사는 응시자가 단순한 이분법적(Yes/No) 답변이나 단일 선다형 답변을 넘어, **서로 상충하거나 상호보완적인 3가지 성향 꼭지점(A, B, C)** 사이에서 자신의 성향이 어느 쪽에 더 가깝게 위치하는지를 **2차원 정삼각형 평면 상의 좌표로 표현**하도록 유도하는 특화 성향검사입니다.

* **동적 다차원 측정**: 하나의 질문에 대해 세 가지 극단적인 선택지 사이의 기여 비율(기본 100% 분배 구조)을 응시자가 마우스 클릭이나 터치로 직접 지정합니다.
* **유연한 결과 분포**: 단순히 'A성향이다' 혹은 'B성향이다' 같은 분류를 넘어, 'A성향 50%, B성향 30%, C성향 20%'와 같은 미세한 정량적 내분점 분포를 수치화하여 도출할 수 있습니다.

---

## 2. 검사방법

1. **소속 카테고리 진입**: 사용자는 데브스펙트럼 테스트 목록에서 원하는 삼각성향검사 카드를 선택해 응시를 시작합니다.
2. **좌표 찍기**: 각 문항마다 화면에 정삼각형 모양의 2D 차트 영역이 제공됩니다. 삼각형의 세 꼭지점에는 각각 지정된 성향의 핵심 키워드(레이블)가 표시됩니다.
3. **가까운 위치 지정**: 응시자는 세 성향 중 자신이 더 동의하거나 선호하는 방향에 가깝게 삼각형 내부를 클릭합니다. 꼭지점에 가까워질수록 해당 성향의 비중이 100%에 수렴하며, 한가운데(무게중심)에 찍을 경우 세 꼭지점의 비중이 정확히 33.3%씩 균등 배분됩니다.
4. **진척도 저장 및 제출**: 모든 문항의 위치 지정이 완료되면 답변을 서버로 제출하여 분석을 가동합니다.

---

## 3. 질문작성방법 (관리자 가이드)

관리자 대시보드의 삼각검사 관리 탭에서 다음과 같이 문항을 설계합니다.

1. **질문 내용 작성**: 해당 문항이 다루고자 하는 상황이나 행동 양식을 서술형으로 작성합니다.
   * *예: "프로젝트 진행 과정에서 예기치 못한 스펙 변경 요청이 발생했을 때, 당신은 어떻게 행동합니까?"*
2. **꼭지점 A, B, C 설정**:
   * 각 꼭지점은 서로 대립되거나 명확한 차별성을 가지는 성향이어야 결과의 해상도가 높아집니다.
   * **레이블**: 꼭지점 모퉁이에 노출할 짧은 성향 키워드를 기입합니다.
   * **설명**: 꼭지점에 가깝게 찍었을 때의 구체적인 의미를 서술합니다.
   * **연결 성향**: 해당 꼭지점 선택 시 지분을 얻게 될 **검사대상성향(Trait)**을 연계해 줍니다.
3. **질문 정렬 순서**: 문항이 노출될 우선순위(display_order)를 지정합니다. 숫자가 작을수록 시험지 최상단에 배치됩니다.

## 4. 점수부여방식 (무게중심 좌표계)

삼각성향검사는 삼각형 내부의 좌표 $(X, Y)$를 바탕으로 각 성향의 득점 비중을 도출하기 위해 **무게중심 좌표계(Barycentric Coordinates)** 수학적 연산을 적용합니다.

### 1) 계산 공식 개요
정삼각형의 세 꼭지점을 각각 $A(x_a, y_a)$, $B(x_b, y_b)$, $C(x_c, y_c)$라 하고, 응시자가 클릭한 삼각형 내부의 임의의 점을 $P(x, y)$라고 할 때 점 $P$는 세 꼭지점의 선형 결합으로 표현할 수 있습니다.

$$P = w_a \cdot A + w_b \cdot B + w_c \cdot C$$

이때 기여도 가중치 $(w_a, w_b, w_c)$는 다음 조건을 만족하는 유일한 양의 실수 집합입니다.

$$w_a + w_b + w_c = 1 \quad (0 \le w_a, w_b, w_c \le 1)$$

### 2) 실제 계산 프로세스
삼각형 $ABC$의 전체 넓이와 점 $P$에 의해 분할되는 세 세부 삼각형($PBC$, $PCA$, $PAB$)의 넓이 비율을 통해 가중치를 산출합니다.

* **꼭지점 A 점수 ($w_a$)** = $\triangle PBC$의 넓이 / $\triangle ABC$의 넓이
* **꼭지점 B 점수 ($w_b$)** = $\triangle PCA$의 넓이 / $\triangle ABC$의 넓이
* **꼭지점 C 점수 ($w_c$)** = $\triangle PAB$의 넓이 / $\triangle ABC$의 넓이

최종 결과 화면 및 제출 기록에는 이 가중치 비율을 백분율(%)로 환산하여 소수점 첫째 자리까지 표시합니다.
$$Score_A = w_a \times 100 (\%), \quad Score_B = w_b \times 100 (\%), \quad Score_C = w_c \times 100 (\%)$$

---

## 5. 결과지작성방법 (결과 유형 설정)

삼각성향검사는 산출된 백분율(%) 비중 구간에 따라 맞춤형 결과 리포트를 출력합니다.

1. **대상 성향 매칭**: 일괄 결과지 추가 다이얼로그에서 특정 성향(예: '적극성')을 선택합니다.
2. **구간 조건 지정**: 해당 성향의 획득 점수 백분율(%)이 어느 범위에 속할 때 이 리포트를 출력할지 지정합니다.
   * **최소값 & 경계조건**: 예: `30` `%` `이상` 또는 `초과`
   * **최대값 & 경계조건**: 예: `70` `%` `이하` 또는 `미만`
3. **리포트 텍스트 및 이미지 설정**:
   * **성향결과명**: 해당 성향 구간을 정의하는 타이틀을 입력합니다. (예: "균형 잡힌 주도자")
   * **리포트 해설**: 해당 구간의 성향을 가진 사람들의 행동적 장단점, 협업 가이드라인, 추천 개발 직군 해설 등을 상세히 기입합니다.
   * **결과 이미지**: 구간을 상징하는 커스텀 이미지를 업로드해 수려한 시각적 효과를 부여합니다.
