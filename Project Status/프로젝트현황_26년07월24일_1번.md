## 2. Technical Stack (기술 스택)

### 프론트엔드 (Frontend)
- **프레임워크 및 라이브러리**: React 19 (`^19.2.3`), React DOM (`^19.2.3`)
- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`) — `Suspense` + `lazy()` 기반 코드 스플리팅 적용 및 `AnonymousRoute` 가드를 통한 비로그인 사용자 전용 경로 보안 처리
- **상태 관리 & 데이터 페칭**:
  - 서버 상태: TanStack Query v5 (`@tanstack/react-query ^5.90.11`) — `keepPreviousData` (placeholderData) 적용으로 줌 조절 및 페이지 전환 시 깜빡임 방지
  - HTTP 클라이언트: Axios (`^1.13.2`) — 요청/응답 인터셉터 기반 자동 JWT 토큰 주입 및 401 처리
  - 전역 클라이언트 상태: React Context API (`AuthContext`, `ContainerWidthContext`)
- **UI 및 스타일링**:
  - UI 컴포넌트: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
  - 스타일링: Emotion (`@emotion/react ^11.14.0`, `@emotion/styled ^11.14.1`)
  - 애니메이션: Framer Motion (`^12.23.25`)
  - 아이콘: Lucide React (`^0.555.0`)
- **성향검사 시각화**: 
  - 삼각검사 시각화: HTML5 Canvas 및 Custom React Component (`TriangleCanvas.tsx`)
  - 종합 성향 분석 시각화: 방사형 다각 그래프 및 가로 막대형 차트 커스텀 구현 (`MultipleChoiceRadialChart.tsx`)
- **리치 텍스트 에디터 (Rich Text Editor)**:
  - React Quill New (`react-quill-new ^3.6.0`), Quill Table Up (`^3.2.2`)
  - 자체 모듈화 커스텀 컴포넌트 (`components/common/rich-text-editor/`)
  - 대표 이미지 고정 슬롯 카드, 특수요소 임시 잘라내기/붙여넣기(`usePasteImage`, `useSpecialElements`) 사이드바 모달
  - 이미지 호버 인디케이터, 테두리/배경색, Border Radius 제어 및 커스텀 색상 palette
- **내보내기 및 캡처**: html2canvas (`^1.4.1`), jsPDF (`^3.0.1`) — 줌 렌더링 및 뷰포트 너비 보정 적용
- **결제 연동**: TossPayments SDK (`@tosspayments/payment-widget-sdk ^0.12.1`)
- **차트 및 시각화**: Recharts (`^3.5.1`)

- **보안 및 살균**: DOMPurify (`^3.3.0`)
- **빌드 도구**: Create React App (`react-scripts 5.0.1`), TypeScript (`^4.9.5`)

### 백엔드 (Backend)
- **런타임 및 웹 서버**: Node.js, Express v5 (`^5.1.0`)
- **타임존 설정**: `process.env.TZ = 'Asia/Seoul'` 및 DB 연결 시 `SET TIMEZONE='Asia/Seoul'` (KST 기준 서버 동작 보장)
- **데이터베이스**: PostgreSQL (`pg ^8.16.3`), 마이그레이션 도구 (`node-pg-migrate ^8.0.3`) — CommonJS 마이그레이션 규칙 준수

- **수학적 점수 환산 알고리즘**: 무게중심 좌표(Barycentric Coordinates) 환산 로직 내장 (삼각검사 전용) 및 선다형 검사용 백분율(기여도) 점수 도출 로직
- **보안 및 인증**: Passport.js (`^0.7.0`), Google OAuth2 (`passport-google-oauth20`), GitHub OAuth2 (`passport-github2`), JWT (`jsonwebtoken ^9.0.2`), BCrypt (`bcrypt ^6.0.0`), Cookie Parser (`cookie-parser ^1.4.7`)
- **파일 업로드**: Multer (`^2.0.2`)
- **입력 유효성 검사**: express-validator (`^7.3.1`)
- **작업 스케줄링**: node-cron (`^4.2.1`)
- **이메일 전송**: Nodemailer (`^7.0.11`) + AWS SES SMTP 연동
- **UUID 생성**: uuid (`^13.0.0`)
- **개발 도구**: ts-node (`^10.9.2`), nodemon (`^3.1.11`), TypeScript (`^5.9.3`)

## 4. 최근 변경사항 및 최신 업데이트 내역 (7월 24일 기준)

### 1) 서버 및 DB KST 타임존(Asia/Seoul) 완전 고정
* **RDS EC2 UTC 시차 해결**:
  - `backend/src/index.ts` 진입점에 `process.env.TZ = 'Asia/Seoul';`을 추가하고 `backend/src/config/database.ts` 커넥션 풀 생성 시 `SET TIMEZONE='Asia/Seoul'`을 실행하여 9시간 시차 오차를 원천 방지하였습니다.
  - 캐러셀 게시글 기간 설정 및 게시글 등록 시각의 시차에 따른 렌더링 누락 문제를 완전하게 해결했습니다.

### 2) 리치 텍스트 에디터(`RichTextEditor`) 구조 모듈화 및 기능 고도화
* **모듈화 및 가독성 개선**:
  - 기존 거대 에디터 컴포넌트를 `frontend/src/components/common/rich-text-editor/` 디렉토리 하위로 분리 모듈화하였습니다.
* **대표이미지 고정 슬롯 카드 및 자동 지정**:
  - 대표 이미지를 명시적으로 관리할 수 있는 카드 슬롯을 제공하며, 미디어 특수요소 입력 시 대표이미지가 지정되어 있지 않은 경우 자동 지정하는 파이프라인을 구축했습니다.
* **특수요소 임시 잘라내기/붙여넣기(Cut & Paste) 사이드바**:
  - 작성 중인 본문 내 특수요소를 손쉽게 제어하고 임시 보관할 수 있는 플로팅 모달/사이드바를 추가했습니다.
* **이미지 세부 커스텀 및 안전 삭제 가드**:
  - 에디터 내 이미지 호버 인디케이터, 테두리 및 배경색, Border Radius 숫자 제어, 색상 팔레트를 탑재했습니다.
  - 이미지 붙여넣기(`usePasteImage`) 시 본문 내에서 사용 중인 첨부 파일이 오삭제되지 않도록 검증 가드를 적용했습니다.

### 3) 게시판 캐러셀 관리자 설정 라벨 및 날짜 오차 보정
* 캐러셀 관리자 설정 UI의 라벨을 보다 명확히 다듬고, 날짜 이동 시 발생하는 시프트 오차를 방지하도록 프론트엔드 관리자 게시판 설정을 보정했습니다.

### 4) 마크다운 소제목/본문 자동 변환 및 3,000줄 검증
* 마크다운 파싱 시 H1(소제목), H2(본문 제목) 자동 변환 및 상단 구분선(`hr`) 자동 연동 로직을 추가하고, 게시글 본문 3,000줄 제한 유효성 검사(`express-validator`)를 도입했습니다.

### 5) GitHub Actions CI/CD 및 Nginx 유지보수 제어
* 배포 중 서비스 일시 중단 안내를 안전하게 제어하기 위해 `backend_deploy.lock` 기반의 독립적 유지보수 모드 제어 흐름을 CI/CD 배포 워크플로우에 적용했습니다.

## 5. 핵심 도메인 및 구현 수칙 준수 현황

### 1) DB 마이그레이션 수칙 준수
* 마이그레이션 도구는 `npx node-pg-migrate`를 사용하며, 파일은 **CommonJS (`exports.up = (pgm) => { ... }`)** 문법을 일탈 없이 엄격히 준수하고 있습니다.
* GitHub Actions 배포 시 `npm run db:migrate`가 자동으로 수행되어 AWS 프로덕션 DB에 반영됩니다.

### 2) 서브모듈 커밋 및 루트 저장소 포인터 커밋 수칙
* `frontend` 및 `backend` 서브모듈 변경 시 서브모듈 커밋 즉시 메인 저장소(`AoID`)에서도 포인터 업데이트 커밋(`git commit -m "chore: update submodule pointer..."`)을 동시 수행하는 규칙을 철저히 준수합니다.

### 3) 서버 환경 및 배포 수칙
* Nginx 실제 설정 파일 위치: EC2 프로덕션의 `/etc/nginx/sites-available/aoid`
* GitHub Actions를 통한 자동 배포 시스템 구축 완료 (수동 push 시 사전 승인 절차 준수).

## 6. 결론 및 향후 관리 방향

AoID 프로젝트는 **약 11.6만 라인(소스 코드 기준 493개 파일)** 규모의 풀스택 플랫폼으로, 타임존 오차 보정, 에디터 모듈화, 미디어 특수요소 제어, 하이브리드 제출 조회 등 고도화된 기능 체계를 안정적으로 다듬어 가고 있습니다.
향후에도 프로젝트 지침 및 수칙에 맞추어 현황 보고서를 수시로 업데이트하여 최신 개발 상태를 투명하고 명확하게 유지하겠습니다.
