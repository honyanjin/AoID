## 3. 기술 스택

### 3.1 프론트엔드
- **프레임워크**: React 19 (`^19.2.3`), React DOM (`^19.2.3`)
- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`)
- **서버 상태 관리**: TanStack Query v5 (`@tanstack/react-query ^5.90.11`)
- **HTTP 클라이언트**: Axios (`^1.13.2`) — `withCredentials: true` 및 요청/응답 케이스 자동 변환
- **UI 라이브러리**: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
- **애니메이션 & 아이콘**: Framer Motion (`^12.23.25`), Lucide React (`^0.555.0`)
- **에디터**: React Quill New (`react-quill-new ^3.6.0`), highlight.js (`11.11.1`)
- **차트**: Recharts (`^3.5.1`)
- **결제**: TossPayments 위젯 SDK (`@tosspayments/payment-widget-sdk ^0.12.1`)
- **알림**: react-toastify (`^11.0.5`)

### 3.2 백엔드
- **런타임 및 서버**: Node.js, Express v5 (`^5.1.0`), TypeScript (`^5.9.3`)
- **타임존 고정**: `process.env.TZ = 'Asia/Seoul'` (진입점) & DB 세션 타임존 `SET TIMEZONE='Asia/Seoul'`
- **데이터베이스**: PostgreSQL (`pg ^8.16.3`), 마이그레이션 `node-pg-migrate ^8.0.3`
- **인증**: Passport.js, OAuth 2.0 (Google, GitHub), JWT (`jsonwebtoken ^9.0.2`), bcrypt
- **파일 업로드**: Multer (`^2.0.2`)
- **AI 서비스**: `@google/generative-ai ^0.24.1` (`gemini-3.6-flash`)

## 5. 핵심 준수 규칙 (AGENTS.md 요약)

1. **작업 완료 수칙**: 승인된 작업계획에 포함된 모든 작업 및 검증을 완료한 후 보고하며, 진행 중 '하겠다'는 예고만 남기고 멈추지 않는다.
2. **프로젝트 현황 문서 수칙**: 지시 시 전체 프로젝트 분석 후 `Project Status/프로젝트현황_YY년MM월DD일_N번.md` 파일로 작성한다.
3. **서브모듈 커밋 수칙**: 서브모듈(`frontend`/`backend`) 커밋 후 즉시 루트 저장소 포인터 커밋(`git add frontend/backend`)을 세트로 수행한다.
4. **Git Push 사전 승인**: 커밋은 자유롭게 진행하되 `git push` 전에는 반드시 사용자 승인을 받는다.
5. **DB 마이그레이션 수칙**:
   - 마이그레이션 파일 작성 시 반드시 **CommonJS (`exports.up = ...`)** 문법 준수.
   - 스크립트 실행 시 `npx node-pg-migrate` 사용.
   - 프로덕션 DB 마이그레이션은 GitHub Actions 배포 시 자동 수행되므로 수동 요청하지 않는다.
6. **서버 타임존 준수**: 한국 표준시(KST, `Asia/Seoul`) 기준 구동을 필수 유지한다.
7. **이모티콘 사용 금지**: 사용자 명시적 지시가 없는 한 답변 및 보고서에 이모티콘 사용을 금지한다.
