## 2. 저장소 구조 및 서브모듈 관리

### 2.1 서브모듈 연동 규칙
- 프론트엔드 또는 백엔드 하위에서 `git commit`을 작성한 경우, 즉시 루트 저장소(`AoID`)에서도 `git add frontend` 또는 `git add backend`를 실행하여 포인터 업데이트 커밋을 세트로 완료해야 합니다.

## 3. 기술 스택 (Technology Stack)

### 3.1 프론트엔드 (Frontend)
- **Framework & Core**: React 19 (`^19.2.3`), React DOM (`^19.2.3`), TypeScript (`^5.9.3`)
- **Routing**: React Router v7 (`react-router-dom ^7.9.6`)
- **State & Data Fetching**: TanStack Query v5 (`@tanstack/react-query ^5.90.11`), Context API (`AuthContext`)
- **HTTP Client**: Axios (`^1.13.2`) — 토큰 자동 삽입 및 카멜케이스/스네이크케이스 변환 인터셉터 적용
- **UI & Component System**: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
- **Styling & Layout**: Vanilla CSS + Emotion CSS-in-JS + 데브스펙트럼 6단계 반응형 뷰포트 유틸리티
- **Animation & Icons**: Framer Motion (`^12.23.25`), Lucide React (`^0.555.0`)
- **Rich Text Editor**: React Quill New (`react-quill-new ^3.6.0`), highlight.js (`11.11.1`)
- **Visualization**: Recharts (`^3.5.1`)
- **Payment SDK**: TossPayments 위젯 SDK (`@tosspayments/payment-widget-sdk ^0.12.1`)
- **Notification**: react-toastify (`^11.0.5`)

### 3.2 백엔드 (Backend)
- **Runtime & Framework**: Node.js, Express v5 (`^5.1.0`), TypeScript (`^5.9.3`)
- **Timezone**: 한국 표준시(KST, `Asia/Seoul`) 고정 설정 (`process.env.TZ = 'Asia/Seoul'`, DB 커넥션 `SET TIMEZONE='Asia/Seoul'`)
- **Database & Migration**: PostgreSQL (`pg ^8.16.3`), `node-pg-migrate ^8.0.3` (총 90개 마이그레이션)
- **Authentication**: Passport.js, OAuth 2.0 (Google, GitHub), JWT (`jsonwebtoken ^9.0.2`), bcrypt
- **File & Media**: Multer (`^2.0.2`), 자체 이미지/동영상 라이브러리 시스템
- **AI Automation**: `@google/generative-ai ^0.24.1` (Gemini API)

## 4. 핵심 시스템 및 아키텍처 분석

### 4.1 데브스펙트럼 (DevSpectrum) 진단 도구
1. **삼각검사 (Triangle Test)**: 개발자의 성향과 역량을 3개 축 지표로 다각 측정하고 결과를 시각화.
2. **객관식검사 (Multiple Choice Test)**: 선택형 진단을 통해 성향 및 스펙트럼 유형을 도출.
3. **막대척도검사 (Bar Scale Test)**: 연속적 스케일 지표를 기반으로 상세 지수 산출.
4. **전체분석 탭 (`OverallAnalysisTab`)**: 검사 결과를 시각화하고 그룹별 응답 및 성향 분포를 종합 분석하는 공용 대시보드.
5. **결과 리포트 출력 규칙**: PDF 저장 및 이미지 복사 시 판형 변형을 방지하기 위해 `PrintPage` Zoom-to-Fit 정비율 스케일링, 수평 레이아웃 고정(`flexDirection: row`, `flexWrap: nowrap`), SVG viewBox 스케일링 조치가 엄격히 적용됨.
6. **반응형 뷰포트 규칙**: 모바일, HD, FHD, QHD, UHD, UFHD 6개 구간 기준을 유틸리티로 고정하여 화면 맞춤형 레이아웃 제공.

### 4.2 AI 활동 및 자동화 (AI Activity System)
- Google Gemini API를 활용한 컨텐츠 생성, AI 봇 활동 모니터링, 프롬프트 버전 관리, 자동 게시글/댓글 생성 및 활동 로그 관리 시스템 구축 완료.

### 4.3 게시판 및 리치 텍스트 에디터 (Board & RichTextEditor)
- 대표 이미지 고정 슬롯, 이미지/동영상 라이브러리 직접 연동, 특수 요소 파서, 코드 하이라이팅을 지원하는 모듈화 에디터 제공.

### 4.4 포인트 및 서비스 결제 (DevCoins & TossPayments)
- 데브코인 충전/차감 및 토스페이먼츠 위젯 SDK를 통한 전자 결제 파이프라인 완성.

## 5. DB 스키마 및 마이그레이션 현황

`backend/database/migrations/` 하위에는 총 90개의 마이그레이션 파일이 작성되어 있으며, 최신 마이그레이션은 다음과 같습니다:

1. `1785500000000_add_is_public_to_submissions.js`
2. `1785510000000_create_email_daily_logs.js`
3. `1785600000000_create_user_activity_logs.js`
4. `1785700000000_alter_traits_image_url_to_text.js`
5. `1785800000000_alter_results_and_questions_image_url_to_text.js`
6. `1785900000000_add_common_overall_description.js`
7. `1786000000000_create_ai_activity_tables.js`
8. `1786100000000_add-display-mode-to-triangle-test-dashboard-layout.js`
9. `1786200000000_ensure_all_missing_system_tables.js`
10. `1786300000000_add_sequence_trait_count_to_tests.js`

### 마이그레이션 수칙
- 백엔드 마이그레이션은 **CommonJS (`exports.up = (pgm) => { ... }`)** 문법만 사용합니다.
- 마이그레이션 실행은 `npx node-pg-migrate`를 사용하며, 프로덕션 반영은 GitHub Actions 배포 시 자동 수행됩니다.

## 6. 배포 파이프라인 및 인프라 구조

1. **CI/CD (GitHub Actions)**: `.github/workflows/deploy.yml`을 통해 메인 브랜치에 코드가 푸시되면 자동으로 빌드, DB 마이그레이션(`npm run db:migrate`), 서버 재시작이 진행됩니다.
2. **Nginx 가상 호스트 설정**: EC2 프로덕션의 실제 Nginx 파일은 `/etc/nginx/sites-available/aoid`에 위치하며, `aoid.kr` 및 `www.aoid.kr` 가상 호스트를 처리합니다.
3. **Push 및 커밋 수칙**: `git push` 실행 전에는 반드시 사용자의 사전 허락("푸시해도 될까요?")을 구해야 합니다. (커밋은 자유)
