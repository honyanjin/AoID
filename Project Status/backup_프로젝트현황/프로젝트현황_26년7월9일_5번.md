### 🔺 3) 삼각성향검사 (Triangle Test)
전체 모션 박스(Motion Box) 기능을 완벽히 대체하여 신규 추가된 핵심 도메인입니다.
- **수학적 점수 환산 알고리즘**:
  - 삼각형 내부의 한 점 $(x, y)$을 꼭지점 삼각 비중인 무게중심 좌표(Barycentric Coordinates)로 변환합니다.
  - 변환 결과는 A, B, C 세 성향(Traits)의 점수로 환산되며, 세 꼭지점 점수의 총합은 10,000점 기준입니다.
- **문항 및 질문 구조**:
  - 각 검사 시트(`triangle_tests`) 하위에 여러 문항(`triangle_test_questions`)을 등록 가능합니다.
  - 문항별 세 꼭지점(Option A, B, C)에는 각각의 텍스트 레이블, 설명, 그리고 매칭할 독립 성향 ID(`option_a_trait_id` 등)를 가집니다.
- **응시 자격 및 제한 필터링**:
  - 회원 등급 제한(`allowed_grade_ids`)을 제공하여 특정 회원 등급만 검사에 응시하도록 제한합니다.
  - 응시 제한 모드(`attempt_limit_type`): 무제한(`unlimited`), 단 1회(`once`), 또는 특정 시간 대기 후 재응시(`interval` - $H$시간 대기) 방식을 제공하며, 백엔드/프론트엔드 양방향에서 완벽히 검증됩니다.
- **실시간 임시 진행도 저장 및 로드**:
  - 사용자가 문제를 풀다가 이탈할 경우를 대비하여 `triangle_test_progress` 테이블을 통한 자동 세션 보존이 구현되었습니다.
  - 프론트엔드에서는 1.5초 디바운스 자동 저장을 돌려 조작이 멈추거나 화면이 전환될 때 데이터를 실시간 업로드하고, 재응시 진입 시 이어 풀기 대화 상자를 통해 직전 인덱스 및 찍어둔 황금색 포인트를 고스란히 복원합니다.
- **제출 완료 시 재진입 차단**:
  - 성향검사 최종 제출(`submitTest`) 완료 시 트랜잭션 내부에서 임시 저장 데이터를 영구 파괴합니다.
  - 질문지 상세 조회 시 해당 테스트에 이미 제출한 이력이 존재할 경우 최신 `lastSubmissionId`를 프론트엔드로 반환하며, 프론트엔드는 질문지 진입을 막고 강제로 결과지 페이지로 `replace: true` 리다이렉트합니다. 결과지 화면 역시 history stack을 대체(replace)하므로 뒤로가기로 우회하여 재진입하는 것을 원천 차단합니다.
- **성향(Traits) 및 결과지(Results) 매칭의 다차원 개편**:
  - 기존의 복합 조건 매핑 테이블(`triangle_test_result_conditions`) 및 `min_a`/`max_a` 등 특정 꼭짓점에 국한된 점수 구조를 파괴하고, **개별 성향(`trait_id`)별 구간 최소/최대값 비교 스키마**로 42번째 마이그레이션(`change_triangle_test_results_to_trait_ranges`)을 통해 전격 개편되었습니다.
  - 사용자가 획득한 각 성향별 백분율 점수(%)와 해당 성향에 설정된 결과지 조건 구간(최소값/최대값 및 연산자 `>`, `>=`, `<`, `<=`)을 동적으로 비교하여 매칭된 모든 성향 결과 유형을 결과지에 동시에 추천합니다.
- **외형 및 레이아웃 설정**:
  - 각 검사 시트별로 대표 이미지(`cover_image_url`) 및 외형 테마(배경색, 투명도, 테두리 스타일/두께/색상 등)를 설정할 수 있습니다.
- **관리자 대시보드 레이아웃 설정 (`TriangleDashboardCustom.tsx`)**:
  - 가변 행/열 제어, 실시간 렌더링 미리보기가 가능한 그리드 레이아웃 관리 컴포넌트로 구성되어 있으며, 설정 완료 시 JSONB 포맷(`layout_data`)으로 데이터베이스에 저장됩니다.

## 🔍 8. 최근 작업 내역 (2026년 7월 8~9일)

### 🔺 ① 삼각성향검사 (Triangle Test) 결과 판정 스키마 및 배치 저장 API 개편
- **결과지 데이터 구조 간소화**: 42번째 마이그레이션을 통해 기존의 다중 테이블 조건 매핑 방식을 단일 테이블 성향(`trait_id`) 기준 점수 범위(`minValue` ~ `maxValue` 및 비교 연산자)로 간소화하였습니다.
- **배치 저장 API 연동**: 관리자 화면에서 성향별 점수 구간에 따른 결과 리포트 데이터를 배열 형태로 전달받아 트랜잭션 내에서 한 번에 갱신하는 배치 저장(`saveTestResultsBatch`) 기능을 구축 및 연동 완료하였습니다.
- **수학적 점수 판정 연동**: 응시자의 최종 무게중심 점수 백분율(%)을 기반으로 dynamic trait 결과 조건을 대조해 해당되는 유형 결과지들(`matchedResults`)을 추출하여 결과 보기 화면으로 제공합니다.

### 🎨 ② 캔버스 및 레이아웃 시각 디자인 정교화
- **레이아웃 개편**: 질문 화면 레이아웃을 1열 단일 컬럼 구조(질문 ➡️ 도움말 ➡️ 캔버스/조작)로 개편하여 뷰 공간 확보 및 가독성을 극대화하였습니다. 도움말 기호(`▲ ◀ ▶`)를 제거하고 3단 카드 레이아웃으로 기획 조정하였습니다.
- **캔버스 디테일**: 삼각형 테두리를 검은색(`#000000`)으로 교체하고 배경을 흰색(`#ffffff`)으로 일관되게 정리하였습니다. 선택 포인트 점을 파란색에서 고급스러운 **황금색**(`#d4af37`) 및 투명 황금 글로우 링 형태로 업그레이드하였습니다.
- **컴포넌트 톤앤매너**: Stepper 진행 상태 바와 다음질문/제출 버튼은 미니멀한 검은색, 이전질문은 흰색 테두리 형태로 리디자인하고 상단 질문 문항 개수 지시 문구는 검은색 배지 형태로 통일하였습니다.

### 💾 ③ 성향검사 실시간 자동 저장 및 제출 완료 후 재진입 원천 가드
- **진행도 세션 보존**: `triangle_test_progress` 테이블을 신설하여 1.5초 디바운싱 조건으로 백엔드 API(`saveTestProgress`)를 연동하여 사용자의 임시 진행 상황을 자동 저장합니다.
- **이어 풀기 시나리오**: 미완료 검사 재접근 시 팝업을 통해 이전 진행률 및 답변 데이터를 복구합니다. React Strict Mode로 인한 팝업 이중 렌더링 노출을 useRef 플래그(`hasPromptedRef`) 기반 락(Lock)을 걸어 극복하였습니다.
- **완료 차단 게이트**: 최종 제출 성공 시 임시 세션을 영구 삭제하며, 제출 이력이 있는 제한된 시트에 대해서는 상세 질문 진입을 원천 차단하고 `replace: true`를 활용해 결과지 리다이렉트함으로써 뒤로가기 우회를 완벽히 방어하였습니다.

- **에디터 빈 여백 포커싱 버그 수정**: 본문에 유튜브, 이미지 등 특수 임베드 블록만 있을 때 빈 여백을 클릭해도 포커스가 유실되어 추가 텍스트 입력이 불가능했던 현상을 `handleWrapperClick` 클릭 위임 제어기를 통해 극복하였습니다.
