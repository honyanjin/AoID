## 🛠️ 2. 기술 스택 (Tech Stack)

### 💻 프론트엔드 (Frontend)
- **프레임워크 및 라이브러리**: React 19 (`^19.2.3`), React DOM (`^19.2.3`)
- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`) — `Suspense` + `lazy()` 기반 코드 스플리팅 전면 적용 및 `AnonymousRoute` 가드를 통한 비로그인 사용자 전용 경로 보안 처리
- **상태 관리 & 데이터 페칭**:
  - 서버 상태: TanStack Query v5 (`@tanstack/react-query ^5.90.11`) — 게시판/관리자 영역에 통합 적용
  - HTTP 클라이언트: Axios (`^1.13.2`)
  - 전역 클라이언트 상태: React Context API (`AuthContext`, `ContainerWidthContext`)
- **UI 및 스타일링**:
  - UI 컴포넌트: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
  - 스타일링: Emotion (`@emotion/react ^11.14.0`, `@emotion/styled ^11.14.1`)
  - 애니메이션: Framer Motion (`^12.23.25`)
  - 아이콘: Lucide React (`^0.555.0`)
- **삼각검사 시각화**: HTML5 Canvas 및 Custom React Component (`TriangleCanvas.tsx`)
  - **통계적 시각화**: 리니어 프로그레스 바 위에 전체 그룹의 평균(Mean) 및 표준편차(stdDev) 범위 박스와 편차 경계선 세로 마커 렌더링, 툴팁 표시

## 🧩 4. 주요 도메인 및 기능 분석 (최신 업데이트 반영)

### 📝 1) 게시판 및 커뮤니티 고도화 (Board & Community) - **[UPDATE]**
* **게시판 섹션(Section) 기능 확장**:
  - 개별 섹션마다 고유의 게시판 스타일(`board_style` - 기본값 `default`, `news` 등)을 다르게 부여할 수 있도록 `board_sections` 테이블에 컬럼이 추가되고 프론트엔드/백엔드 인터페이스가 통합되었습니다.
  - 섹션 레벨에서 공지 전용 게시판 여부를 결정하는 `is_notice_board` 속성이 추가되었습니다.
  - 고정 게시글(Pinned Post)과 일반 공지글(Notice Post) 레이아웃을 프론트엔드단에서 분리하여 시각적 계층 구조가 강화되었습니다.
  - 전체 게시글 보기 뷰에서 공지사항 게시판 여부가 잘못 판정되던 버그가 수정되었습니다.
* **섹션 전용 캐러셀 배너 설정**:
  - 섹션에도 광고/배너 슬라이드를 노출하기 위해 `show_carousel`(boolean) 및 `carousel_ratio_multiplier`(numeric(3,2)) 속성이 탑재되었습니다.
  - 프론트엔드 `SectionManagement.tsx`를 통해 관리자가 활성화 및 화면 표시 비율 가중치를 동적으로 제어할 수 있습니다.
* **뉴스 카드의 미니 미디어 캐러셀 연동 (`NewsCardItem.tsx` [NEW])**:
  - 뉴스 게시판 카드 렌더링 시, 썸네일 영역에 자체 프리미엄 프리뷰 스타일의 미니 미디어 캐러셀을 표시하는 개별 카드 컴포넌트가 신규 구현되었습니다.
  - 이미지가 비어 있을 경우의 placeholder 텍스트 처리를 개선하여 흰색 배경에 맞춰 깔끔하게 정렬되도록 스타일이 보강되었습니다.
* **디폴트 이미지 타입 구분 지원 (`board_default_images`)**:
  - 카테고리나 글 유형별 기본 썸네일을 제공하는 디폴트 이미지 테이블에 `type` 컬럼이 추가되어 'post' 등의 다양한 타입으로 기본 이미지를 구분해 로드하고 매핑할 수 있게 되었습니다.
* **기자 및 작성자 정보 표시 보강 (실명 연동)**:
  - 백엔드의 게시글 조회 쿼리에서 작성자 프로필 정보 외에 실제 실명(`full_name`) 필드를 함께 fetch하도록 쿼리를 수정하여, 기사 등에서 기자의 실명이 정상 렌더링되도록 보완했습니다.

### 🔺 2) 삼각성향검사 (Triangle Test) - **[UPDATE]**
* **카테고리 활성화 토글 (is_active)**:
  - 삼각성향검사 카테고리(`triangle_test_categories`) 관리 화면에 온/오프 스위치(`is_active` 플래그)가 추가되었습니다.
  - 관리자가 비활성화한 카테고리는 일반 사용자 화면에서 보이지 않도록 동적 필터링을 지원합니다.
* **수학적 점수 환산 및 통계 시각화**:
  - 무게중심 좌표(Barycentric Coordinates) 환산 로직 및 100점 척도 스케일링이 정상 동작합니다.
  - 리니어 프로그레스 바 위에서 전체 응시자 평균(Mean) 및 표준편차(stdDev) 범위 박스와 편차 경계 세로 마커를 정교하게 렌더링합니다.
* **실시간 임시 진행도 저장 및 제출 재진입 차단**:
  - `triangle_test_progress` 테이블을 통한 1.5초 디바운스 자동 세션 보존이 지원됩니다.
  - 최종 제출 완료 시 임시 저장 세션이 영구 파괴되며, 뒤로가기 진입 시 결과 리포트로 강제 리다이렉트되어 재진입이 차단됩니다.

### 🔐 3) 경로 보안 가드 (Auth Security) - **[UPDATE]**
* **로그인 사용자 전용 익명 경로 가드 (`AnonymousRoute.tsx` [NEW])**:
  - 이미 로그인하여 세션이 유효한 사용자가 브라우저 URL 입력 등을 통해 로그인 페이지(`LoginPage`)나 회원가입 페이지 (`RegisterPage`)에 접근하려 할 때, 이를 감지하고 홈 화면(`/`)으로 강제 리다이렉션 처리하는 경로 가드가 새롭게 도입되었습니다.
  - 이를 통해 불필요한 이중 로그인 시도를 방지하고 사용자 인증 흐름을 매끄럽게 통제합니다.
