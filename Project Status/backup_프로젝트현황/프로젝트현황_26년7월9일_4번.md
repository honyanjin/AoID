### 🔺 3) 삼각성향검사 (Triangle Test)
전체 모션 박스(Motion Box) 기능을 완벽히 대체하여 신규 추가된 핵심 도메인입니다.
- **수학적 점수 환산 알고리즘**:
  - 삼각형 내부의 한 점 $(x, y)$을 꼭지점 삼각 비중인 무게중심 좌표(Barycentric Coordinates)로 변환합니다.
  - 변환 결과는 A, B, C 세 성향(Traits)의 점수로 환산되며, 세 꼭지점 점수의 총합은 10,000점 기준입니다.
- **문항 및 질문 구조**:
  - 각 검사 시트(`triangle_tests`) 하위에 여러 문항(`triangle_test_questions`)을 등록 가능합니다.
  - 문항별 세 꼭지점(Option A, B, C)에는 각각의 텍스트 레이블, 설명, 그리고 매칭할 독립 성향 ID(`option_a_trait_id` 등)를 가집니다.
- **응시 자격 및 제한 필터링**:
  - 회원 등급 제한(`allowed_grade_ids`)을 제공하여 특정 회원 등급만 검사에 응시하도록 제한합니다.
  - 응시 제한 모드(`attempt_limit_type`): 무제한(`unlimited`), 단 1회(`once`), 또는 특정 시간 대기 후 재응시(`interval` - $H$시간 대기) 방식을 제공하며, 백엔드/프론트엔드 양방향에서 완벽히 검증됩니다.
- **실시간 임시 진행도 저장 및 로드**:
  - 사용자가 문제를 풀다가 이탈할 경우를 대비하여 `triangle_test_progress` 테이블을 통한 자동 세션 보존이 구현되었습니다.
  - 프론트엔드에서는 1.5초 디바운스 자동 저장을 돌려 조작이 멈추거나 화면이 전환될 때 데이터를 실시간 업로드하고, 재응시 진입 시 이어 풀기 대화 상자를 통해 직전 인덱스 및 찍어둔 황금색 포인트를 고스란히 복원합니다.
- **제출 완료 시 재진입 차단**:
  - 성향검사 최종 제출(`submitTest`) 완료 시 트랜잭션 내부에서 임시 저장 데이터를 영구 파괴합니다.
  - 질문지 상세 조회 시 해당 테스트에 이미 제출한 이력이 존재할 경우 최신 `lastSubmissionId`를 프론트엔드로 반환하며, 프론트엔드는 질문지 진입을 막고 강제로 결과지 페이지로 `replace: true` 리다이렉트합니다. 결과지 화면 역시 history stack을 대체(replace)하므로 뒤로가기로 우회하여 재진입하는 것을 원천 차단합니다.
- **외형 및 레이아웃 설정**:
  - 각 검사 시트별로 대표 이미지(`cover_image_url`) 및 외형 테마(배경색, 투명도, 테두리 스타일/두께/색상 등)를 설정할 수 있습니다.
- **관리자 대시보드 레이아웃 설정 (`TriangleDashboardCustom.tsx`)**:
  - 가변 행/열 제어, 실시간 렌더링 미리보기가 가능한 컴포넌트로 구성되어 있으며, 설정 완료 시 JSONB 포맷(`layout_data`)으로 데이터베이스에 저장됩니다.
- **성향(Traits) 및 결과지(Results) 매칭**:
  - 동적 성향(`triangle_test_traits`)별 획득 점수의 최소/최대 임계값 범위를 조건(`triangle_test_result_conditions`)으로 매치하여 적절한 결과지(`triangle_test_results`)를 자동 추천합니다.

- **프론트엔드**: 질문 화면 레이아웃을 1열 단일 컬럼 구조(질문 ➡️ 도움말 ➡️ 캔버스/조작)로 개편하여 뷰 공간 확보 및 가독성 대폭 향상. 꼭지점 성향 도움말의 기호(`▲ ◀ ▶`)를 삭제하고 3단 카드 형태로 가공 조정. 캔버스 안내 문구 내 `🎨` 아이콘 삭제 및 상세 안내 문구 교체.
- **캔버스 드로잉**: 캔버스 크기 변화 시 꼭지점 좌표 상태(`triangleVertices`)와 픽셀 매핑하여 텍스트 상자 위치가 유기적으로 따라가게 수학적 추적 기능 고도화. 캔버스 배경 및 삼각형 내부를 완전 흰색(`#ffffff`)으로 정리하고 외각 테두리를 선명한 검은색(`#000000`)으로 교체. 포인트 점 색상을 파란색에서 고급스러운 **황금색**(`#d4af37`) 및 투명 황금 글로우 링으로 업그레이드.
- **컴포넌트 톤앤매너**: Stepper의 진행도를 검은색 바 형태로 교체하고, 다음질문 및 제출 버튼을 검은색 배경/흰색 라벨로, 이전질문 버튼을 흰색 배경/검은색 라벨 테두리로 미니멀하게 리디자인. 상단 Question 질문 개수 지시 문구는 검은색 배지 형태에 흰색 라벨을 조화시켜 시각 위계를 재정렬.

### 💾 ③ 성향검사 실시간 자동 저장 및 제출 완료 후 재진입 원천 가드 구현 (7월 9일 추가)
- **임시저장 세션 보류**: `triangle_test_progress` 테이블을 신설하는 신규 데이터베이스 마이그레이션(`create-triangle-test-progress`)을 성공적으로 완료하여 사용자의 테스트별 실시간 진행 상태를 저장하도록 확장.
- **디바운싱 임시저장**: 문항이 바뀌거나 드래그 조작이 멈춘 지 1.5초(1500ms) 경과 시 백엔드 API(`saveTestProgress`)로 상태를 조용히 자동 백업하는 훅을 설계하여 서버 과부하를 막으면서 진행도를 안전하게 보관.
- **이어 풀기 시나리오**: 미완료 검사 재접근 시 컨펌 다이얼로그를 통해 데이터(`currentIdx`, `answers`)를 통째로 복구해 주는 로직 연동. React Strict Mode로 인한 다이얼로그 중복/이중 렌더링 노출 현상을 막기 위해 useRef 플래그(`hasPromptedRef`) 기반의 팝업 제어 락(Lock)을 구현해 1회만 표시되게 수정 완료.
- **완료 차단 게이트 (다중 응시 연동)**: 결과 최종 제출 시 임시저장 레코드를 즉시 삭제. 사용자의 신규 응시 자격(Eligibility)이 없는 경우(1회 한정 검사 완료 상태, 혹은 쿨타임 미경과 상태 등)에만 조회 API에서 `lastSubmissionId`를 제공하며, 프론트엔드는 이 경우에만 결과지(/triangle-test/result/:submissionId)로 `replace: true` 강제 리다이렉트합니다. 만약 쿨타임이 지났거나 무제한 응시 가능한 시트라면 튕겨내지 않고 새 질문지를 로딩하도록 예외 조건을 고도화했습니다. 결과지 이동 시에도 history replace를 걸어 완벽하게 우회 진입을 방지함.

- **YouTube 삽입 툴 동영상 URL 동적 분기**: 유튜브 URL 입력 창(`createYoutubeHandler`)에서 사용자가 일반 동영상 파일 주소(.mp4, .webm 등)를 입력하더라도 에러를 내지 않고 자동으로 HTML5 비디오 블록(`custom-video`)으로 유연하게 변환해 삽입해 주는 하이브리드 입력 기능 탑재.
