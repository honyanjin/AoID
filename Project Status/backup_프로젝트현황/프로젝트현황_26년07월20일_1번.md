## 1. 프로젝트 규모 및 통계 (Project Metrics)

현재 기준으로 프론트엔드는 **332개 파일 / 85,299줄**, 백엔드는 **140개 파일 / 22,982줄**로 집계됩니다.
전체 합산은 **472개 파일 / 108,281줄**로, **총 소스 코드 규모 약 10.8만 라인(LoC)**입니다.

## 2. 기술 스택 (Tech Stack)

### 프론트엔드 (Frontend)
- **프레임워크 및 라이브러리**: React 19 (`^19.2.3`), React DOM (`^19.2.3`)
- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`) — `Suspense` + `lazy()` 기반 코드 스플리팅 전면 적용 및 `AnonymousRoute` 가드를 통한 비로그인 사용자 전용 경로 보안 처리

  - 서버 상태: TanStack Query v5 (`@tanstack/react-query ^5.90.11`) — 게시판/관리자 영역에 통합 적용
  - HTTP 클라이언트: Axios (`^1.13.2`)
  - 전역 클라이언트 상태: React Context API (`AuthContext`, `ContainerWidthContext`)
- **UI 및 스타일링**:
  - UI 컴포넌트: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
  - 스타일링: Emotion (`@emotion/react ^11.14.0`, `@emotion/styled ^11.14.1`)
  - 애니메이션: Framer Motion (`^12.23.25`)
  - 아이콘: Lucide React (`^0.555.0`)
- **삼각검사 시각화**: HTML5 Canvas 및 Custom React Component (`TriangleCanvas.tsx`)
  - **통계적 시각화**: 리니어 프로그레스 바 위에 전체 그룹의 평균(Mean) 및 표준편차(stdDev) 범위 박스와 편차 경계선 세로 마커 렌더링, 툴팁 표시

## 4. 주요 도메인 및 기능 분석 (최신 업데이트 반영)

### 1) 데브스펙트럼 및 선다형 성향검사 (DevSpectrum & Multiple Choice Test) *[최신 변경사항]*
* **데브스펙트럼 통합 카테고리 개편**:
  - 기존에 삼각성향검사 전용으로 사용되던 `triangle_test_categories` 테이블을 `dev_spectrum_categories`로 이름을 변경하여 다양한 유형의 성향검사를 통합 수용할 수 있는 구조로 확장하였습니다.
* **선다형 성향검사(Multiple Choice Test) 데이터 스키마 유연성 확보**:
  - 결과 테이블(`multiple_choice_test_results`)에서 최소/최대 점수 제한(`min_value`, `max_value`) 체크 제약 조건(0~100 범위 제한)을 삭제하여, 100점을 초과하거나 다른 특수 점수 범위를 가질 수 있도록 유연하게 개선하였습니다.
  - 성향 테이블(`multiple_choice_test_traits`)에 `max_base_score` 컬럼(기본값 100)을 추가하여 각 측정 성향별 최대 기준 점수를 동적으로 정의할 수 있는 발판을 마련했습니다.
* **백엔드 채점 알고리즘 및 임시진행저장 API**:
  - `multipleChoiceTestController.ts`를 통해 사용자별 검사 응답 및 결과를 채점하고, 각 성향별 기여도 백분율을 도출하여 주성향(`dominant_trait_id`)을 계산하는 로직을 제공합니다.
  - 사용자가 시험 중간에 임시 저장할 수 있는 세션 관리 기능(`multiple_choice_test_progress` 활용)이 지원됩니다.
* **프론트엔드 검사 관리자 UI 도입**:
  - `MultipleChoiceTestManagement.tsx` 컴포넌트를 통해 시험지 설정, 측정할 성향 등록, N지선다 문항 및 선택지별 가중치 할당, 점수대별 결과 분석지를 손쉽게 일괄 생성 및 관리할 수 있도록 어드민 기능을 구축하였습니다.

### 2) 게시판 및 커뮤니티 고도화 (Board & Community)
* **게시판 섹션(Section) 기능 확장**:
  - 개별 섹션마다 고유의 게시판 스타일(`board_style` - 기본값 `default`, `news` 등)을 다르게 부여할 수 있도록 `board_sections` 테이블에 컬럼이 추가되고 프론트엔드/백엔드 인터페이스가 통합되었습니다.
  - 섹션 레벨에서 공지 전용 게시판 여부를 결정하는 `is_notice_board` 속성이 추가되었습니다.
  - 고정 게시글(Pinned Post)과 일반 공지글(Notice Post) 레이아웃을 프론트엔드단에서 분리하여 시각적 계층 구조가 강화되었습니다.
* **뉴스레터 이미지 리소스 정리 및 검증**:
  - 기존 뉴스레터 내 리스팅된 11개의 엑박 이미지(404)를 검증된 Unsplash 이미지 및 실동작 핫링크 리소스로 최종 교체하였습니다.
  - SpaceX 및 X 공식 로고를 Wikimedia Commons 실동작 URL로 교체하여 시각적 완성도를 높였으며, Fail-safe 텍스트 링크 목록을 마련했습니다.
* **글쓰기 버튼 활성화 논리 개선**:
  - `BoardLayout.tsx`에서 전체 카테고리 보기(`all`) 상태라 하더라도, 하위 카테고리 중 `writeButtonAlwaysActive`가 활성화되어 있는 카테고리가 존재한다면 글쓰기 버튼이 비활성화되지 않고 상시 활성화되도록 프론트엔드 비즈니스 로직을 보완하였습니다.

### 3) 관리자 게시글 일괄 관리 및 뉴스 파싱 기능 (Admin Features)
* **임시 게시글 일괄 등록 및 뉴스 마크다운 파싱**:
  - 뉴스레터 등 마크다운 형식으로 구성된 외부 원고 소스를 파싱하여 게시글 형태로 자동 변환 및 변환 데이터를 일괄 수집하는 기능이 백엔드 및 관리자 페이지에 도입되었습니다.
* **게시글 일괄 변경 및 삭제**:
  - 다수의 게시글을 일괄적으로 삭제(`bulkDeletePosts`)하거나 공개/비공개 상태를 일괄 변경(`bulkUpdatePublishStatus`)할 수 있는 API와 다이얼로그 UI(`PostsManagement.tsx`)를 구축하였습니다.
* **조회 정렬 기준 개선**:
  - 관리자용 게시글 목록 조회 API에서 최근에 등록된 데이터가 상단에 직관적으로 배치되도록 정렬 방식을 ID 내림차순(`p.id DESC`)으로 고도화하였습니다.

### 4) 삼각성향검사 (Triangle Test)
* **카테고리 활성화 토글 (is_active)**:
  - 삼각성향검사 카테고리 관리 화면에 온/오프 스위치(`is_active` 플래그)가 추가되어 관리자가 직접 활성화 유무를 결정할 수 있습니다.
* **수학적 점수 환산 및 통계 시각화**:
  - 무게중심 좌표(Barycentric Coordinates) 환산 로직 및 100점 척도 스케일링이 정상 동작합니다.
  - 리니어 프로그레스 바 위에서 전체 응시자 평균(Mean) 및 표준편차(stdDev) 범위 박스와 편차 경계 세로 마커를 렌더링합니다.
* **실시간 임시 진행도 저장 및 제출 재진입 차단**:
  - `triangle_test_progress` 테이블을 통한 1.5초 디바운스 자동 세션 보존이 지원됩니다.
  - 최종 제출 완료 시 임시 저장 세션이 파괴되며 결과 리포트로 강제 리다이렉트 처리됩니다.

### 5) TossPayments 결제 (Payment)
- TossPayments 위젯 → 결제 요청 → `/api/payments/confirm` 콜백 → 결과 페이지 (success/fail) 흐름이 유지됩니다.
