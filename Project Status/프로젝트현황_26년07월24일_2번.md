## 2. Technical Stack (기술 스택)

### 프론트엔드 (Frontend)
- **프레임워크 및 라이브러리**: React 19 (`^19.2.3`), React DOM (`^19.2.3`)
- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`) — `Suspense` + `lazy()` 기반 코드 스플리팅 적용 및 `AnonymousRoute` 가드를 통한 비로그인 사용자 전용 경로 보안 처리
- **상태 관리 & 데이터 페칭**:
  - 서버 상태: TanStack Query v5 (`@tanstack/react-query ^5.90.11`) — `keepPreviousData` (placeholderData) 적용으로 줌 조절 및 페이지 전환 시 깜빡임 방지
  - HTTP 클라이언트: Axios (`^1.13.2`) — 요청/응답 인터셉터 기반 자동 JWT 토큰 주입 및 401 처리
  - 전역 클라이언트 상태: React Context API (`AuthContext`, `ContainerWidthContext`)
- **UI 및 스타일링**:
  - UI 컴포넌트: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
  - 스타일링: Emotion (`@emotion/react ^11.14.0`, `@emotion/styled ^11.14.1`)
  - 애니메이션: Framer Motion (`^12.23.25`)
  - 아이콘: Lucide React (`^0.555.0`)
- **수익화 및 광고 연동**: Google AdSense Client Script Head 연동 (`pub-8370196278440513`)
- **성향검사 시각화**: 
  - 삼각검사 시각화: HTML5 Canvas 및 Custom React Component (`TriangleCanvas.tsx`)
  - 종합 성향 분석 시각화: 방사형 다각 그래프 및 가로 막대형 차트 커스텀 구현 (`MultipleChoiceRadialChart.tsx`)
- **리치 텍스트 에디터 (Rich Text Editor)**:
  - React Quill New (`react-quill-new ^3.6.0`), Quill Table Up (`^3.2.2`)
  - 자체 모듈화 커스텀 컴포넌트 (`components/common/rich-text-editor/`)
  - 대표 이미지 고정 슬롯 카드, 특수요소 임시 잘라내기/붙여넣기(`usePasteImage`, `useSpecialElements`) 사이드바 모달
  - 이미지 호버 인디케이터, 테두리/배경색, Border Radius 제어 및 커스텀 색상 palette
- **내보내기 및 캡처**: html2canvas (`^1.4.1`), jsPDF (`^3.0.1`) — 줌 렌더링 및 뷰포트 너비 보정 적용
- **결제 연동**: TossPayments SDK (`@tosspayments/payment-widget-sdk ^0.12.1`)
- **차트 및 시각화**: Recharts (`^3.5.1`)
- **날짜 처리**: date-fns (`^4.1.0`)
- **SEO**: react-helmet-async (`^3.0.0`) 및 서버 사이드 동적 메타주입 연동
- **보안 및 살균**: DOMPurify (`^3.3.0`)
- **빌드 도구**: Create React App (`react-scripts 5.0.1`), TypeScript (`^4.9.5`)

### 백엔드 (Backend)
- **런타임 및 웹 서버**: Node.js, Express v5 (`^5.1.0`)
- **타임존 설정**: `process.env.TZ = 'Asia/Seoul'` 및 DB 연결 시 `SET TIMEZONE='Asia/Seoul'` (KST 기준 서버 동작 보장)
- **데이터베이스**: PostgreSQL (`pg ^8.16.3`), 마이그레이션 도구 (`node-pg-migrate ^8.0.3`) — CommonJS 마이그레이션 규칙 준수

- **파일 업로드**: Multer (`^2.0.2`)
- **입력 유효성 검사**: express-validator (`^7.3.1`)
- **작업 스케줄링**: node-cron (`^4.2.1`)
- **이메일 전송**: Nodemailer (`^7.0.11`) + AWS SES SMTP 연동
- **UUID 생성**: uuid (`^13.0.0`)
- **개발 도구**: ts-node (`^10.9.2`), nodemon (`^3.1.11`), TypeScript (`^5.9.3`)

## 4. 최근 주요 변경사항 및 최신 업데이트 내역 (7월 24일 2차 기준)

### 1) 사용자 활동 로그(Activity Logging System) & 관리자 UI 구축
* **백엔드 활동 기록 기능**:
  - 사용자 주요 행위(로그인, 게시글 작성, 댓글 작성, 검사 제출 등)를 추적 기록하는 `activityLogService` 및 라우트를 도입하였습니다.
  - 관리자 대시보드에서 활동 유형, 기간, 사용자별 검색이 가능한 `activityLogAdminController` API를 탑재했습니다.
* **프론트엔드 관리자 탭 구현**:
  - `components/admin/activity/UserActivityLogTab.tsx`를 구현하여 사용자 활동 이력을 한눈에 모니터링할 수 있는 UI를 완성했습니다.

### 2) 서버 사이드 동적 SEO 메타 태그 주입 (SEO Meta-Injection) & Bot Detection
* **서버 사이드 OpenGraph/Twitter 메타 생성**:
  - `backend/src/services/seoService.ts`를 신설하여 검색 엔진 크롤러나 SNS 스크랩 요청 시 동적으로 게시글 정보 기반 메타 태그를 주입하는 기능을 구현했습니다.
  - 프론트엔드 빌드 `index.html` 경로 탐색 후보(`candidate paths`)를 강화하여 운영 서버 환경별 경로 정합성을 보장했습니다.
* **비공개 게시글 보안 및 noindex 처리**:
  - 비공개 또는 권한 미달 게시글 요청 시 `noindex, nofollow` 로봇 태그를 동적으로 부여하고 응답 캐싱을 비활성화하여 검출 이슈를 차단했습니다.

### 3) 프론트엔드 URL 동기화 및 관리자 게시글 미리보기 보정
* 관리자 게시글 미리보기(`post preview`) 및 `PostDetailPage`에서 섹션 슬러그(`parent_section`)를 올바르게 추적하도록 백엔드 `getAdminPosts` 쿼리를 보정하고, 프론트엔드 레거시 게시판 URL 동기화 및 섹션 URL 자동 보정을 구현했습니다.

### 4) 구글 애드센스 (Google AdSense) 연동
* `index.html` `head` 태그에 게시자 ID(`pub-8370196278440513`) 스크립트를 통합하고, 사이드바 디스플레이 광고 단위(`3858416151`) 등 광고 컴포넌트를 정립했습니다.

### 5) NewsMaker 서브모듈 체계화
* `NewsMaker` 전용 서브모듈 연동 및 `.gitmodules` 구성을 완료하고, AI 뉴스 제작 지침(`뉴스제작지침.md`) 및 일자별 뉴스 콘텐츠 구조화 체계를 정립했습니다.

## 5. 핵심 도메인 및 구현 수칙 준수 현황

### 1) DB 마이그레이션 수칙 준수
* 마이그레이션 실행 시 `npx node-pg-migrate`를 사용하며, 파일은 **CommonJS (`exports.up = (pgm) => { ... }`)** 문법을 엄격히 준수합니다.
* GitHub Actions 배포 시 `npm run db:migrate`가 자동으로 수행되어 AWS 프로덕션 DB에 반영되므로 프로덕션 수동 마이그레이션 요청을 금지합니다.

### 2) 서브모듈 커밋 및 루트 저장소 포인터 커밋 수칙
* `frontend`, `backend`, `NewsMaker` 서브모듈 변경 시 서브모듈 커밋 즉시 메인 저장소(`AoID`)에서도 포인터 업데이트 커밋(`git commit -m "chore: update submodule pointer..."`)을 동시 수행합니다.

### 3) 서버 환경 및 배포 수칙
* Nginx 실제 설정 파일 위치: EC2 프로덕션의 `/etc/nginx/sites-available/aoid`
* **배포는 GitHub Actions를 통해 자동 수행**되며, `git push` 실행 전에 반드시 사용자 허락을 받습니다.

## 6. 결론 및 향후 개발 가이드

AoID 프로젝트는 **총 497개 소스 파일 / 약 11.7만 라인 (117,027 LoC)** 규모의 풀스택 웹 애플리케이션으로 성장하였습니다.
최근 활동 로그 시스템, SEO 메타주입 서비스, 애드센스 연동 및 URL 동기화 로직이 성공적으로 구현되었으며, 백엔드와 프론트엔드의 타임존(Asia/Seoul) 및 마이그레이션 수칙이 견고하게 유지되고 있습니다.

본 프로젝트 현황 보고서를 바탕으로 사용자의 개발 요청 사항(기능 추가, 버그 수정, 리팩토링, 문서 업데이트 등)을 신속하고 완벽하게 지원할 모든 준비가 완료되었습니다.
