## 2. Technical Stack (기술 스택)

### 프론트엔드 (Frontend)
- **프레임워크 및 라이브러리**: React 19 (`^19.2.3`), React DOM (`^19.2.3`)
- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`) — `Suspense` + `lazy()` 기반 코드 스플리팅 적용 및 `AnonymousRoute` 가드를 통한 비로그인 사용자 전용 경로 보안 처리
- **상태 관리 & 데이터 페칭**:
  - 서버 상태: TanStack Query v5 (`@tanstack/react-query ^5.90.11`) — `keepPreviousData` (placeholderData) 적용으로 줌 조절 및 페이지 전환 시 깜빡임 방지
  - HTTP 클라이언트: Axios (`^1.13.2`)
  - 전역 클라이언트 상태: React Context API (`AuthContext`, `ContainerWidthContext`)
- **UI 및 스타일링**:
  - UI 컴포넌트: Material-UI v7 (`@mui/material ^7.3.5`, `@mui/icons-material ^7.3.5`)
  - 스타일링: Emotion (`@emotion/react ^11.14.0`, `@emotion/styled ^11.14.1`)
  - 애니메이션: Framer Motion (`^12.23.25`)
  - 아이콘: Lucide React (`^0.555.0`)
- **성향검사 시각화**: 
  - 삼각검사 시각화: HTML5 Canvas 및 Custom React Component (`TriangleCanvas.tsx`)
  - 종합 성향 분석 시각화: 방사형 다각 그래프 및 가로 막대형 차트 커스텀 구현 (`MultipleChoiceRadialChart.tsx`)
- **리치 텍스트 에디터**: React Quill New (`react-quill-new ^3.6.0`), Quill Table Up (`^3.2.2`) 및 자체 커스텀 모듈 (`RichTextEditor.tsx`, `usePasteImage`, `useSpecialElements`)

- **결제 연동**: TossPayments SDK (`@tosspayments/payment-widget-sdk ^0.12.1`)
- **차트 및 시각화**: Recharts (`^3.5.1`)

- **보안 및 살균**: DOMPurify (`^3.3.0`)
- **빌드 도구**: Create React App (`react-scripts 5.0.1`), TypeScript (`^4.9.5`)

### 백엔드 (Backend)
- **런타임 및 웹 서버**: Node.js, Express v5 (`^5.1.0`)
- **데이터베이스**: PostgreSQL (`pg ^8.16.3`), 마이그레이션 도구 (`node-pg-migrate ^8.0.3`)

- **파일 업로드**: Multer (`^2.0.2`)
- **입력 유효성 검사**: express-validator (`^7.3.1`)
- **작업 스케줄링**: node-cron (`^4.2.1`)
- **이메일 전송**: Nodemailer (`^7.0.11`)
- **UUID 생성**: uuid (`^13.0.0`)
- **개발 도구**: ts-node (`^10.9.2`), nodemon (`^3.1.11`), TypeScript (`^5.9.3`)

## 4. 최근 최신 변경사항 (7월 22일 2차 기준 추가 반영)

### 1) 댓글 작성 시 관리자 "선호 대리 작성자(Favorite Proxy Authors)" 선택 기능
* **관리자 전용 대리 작성 편의성 강화**:
  - 관리자가 댓글 작성 시 사전에 지정된 선호 대리 작성자 목록에서 빠르게 아이디/프로필을 선택하여 작성할 수 있도록 프론트엔드 댓글 입력 UI(`frontend/src/components/comment/`)를 개선했습니다.

### 2) 사이드바 게시글 목록 박스(`PostListBox`) 및 섹션/카테고리 노출 토글
* **사이드바 게시글 목록 배치 및 흐름 효과**:
  - 게시판 사이드바 영역에 `PostListBox` 컴포넌트를 탑재하여 인기/최신 게시글을 전광판(Auto-Marquee) 형태로 노출하고, 섹션 및 카테고리별 표시 여부를 관리자/사용자가 유연하게 제어할 수 있는 토글 기능을 추가했습니다.

### 3) 특보(`special_news`) 게시판 스타일 작성자/기자 박스 하단 배치
* **기사 스타일 레이아웃 정교화**:
  - 특보 게시판 상세 페이지 렌더링 시 기자/작성자 정보 박스가 본문 최하단에 자연스럽게 배치되도록 조정하여 언론 기사 형태의 가독성을 높였습니다.

### 4) 백엔드 캐러셀 날짜 쿼리 Asia/Seoul 타임존 적용
* **RDS 서버 UTC 시차로 인한 게시글 누락 보정**:
  - RDS AWS 환경(UTC)에서 캐러셀 게시글 날짜 비교 쿼리 수행 시 한국 시각 자정 넘김과 시차로 인해 게시글이 늦게 반영되는 현상을 방지하고자 SQL Query 수준에서 `AT TIME ZONE 'Asia/Seoul'` 기준을 명시 적용하였습니다.

### 5) 브라우저 Zoom 조절 시 렌더링 깜빡임 방지 (keepPreviousData)
* **사용자 경험(UX) 개선**:
  - 화면 확대/축소나 뷰포트 변경 시 limit 파라미터 재계산 과정에서 데이터 깜빡임이 발생하는 문제를 해결하기 위해 TanStack Query의 `placeholderData: keepPreviousData` 처리를 도입했습니다.

## 5. 핵심 도메인 및 기존 주요 기능 요약

### 1) 종합 성향 분석(Overall Analysis) 및 최선최악(Best/Worst) 결과 관리
* 다중 성향 조합 결과를 보관하기 위한 `multiple_choice_overall_results`와 `triangle_overall_results` 스키마 및 최선/최악 조합 테이블 운영
* 관리자 대시보드 `OverallAnalysisTab.tsx`를 통해 성향 조합별 설명 및 대표 이미지를 동적으로 설정하고 일괄 저장/페이지네이션 기능 제공

### 2) 제출 기록 UUID 도입 및 백엔드 Dual-mode (하이브리드) 조회
* 숫자로 된 `submissionId` 노출 방지를 위해 `uuid` 컬럼 소급 적용
* 백엔드 API에서 UUID 형식과 숫자 ID 형식을 자동 감지하여 처리하는 하이브리드 조회 구현

### 3) 삼각성향검사 성향 최고기준점(`max_base_score`) 유연화
* 성향별 가중치 조절을 위해 `max_base_score` 컬럼을 도입하고 관리자 페이지에서 수정 및 일괄 저장 가능하도록 구현

## 6. 결론 및 향후 관리 방향

AoID 프로젝트는 프론트엔드와 백엔드 합산 약 **12.4만 라인** 규모의 TypeScript 기반 풀스택 플랫폼으로, 안정적인 아키텍처와 상세한 동적 게시판/성향검사/관리자 제어 기능을 완비하고 있습니다.
프로젝트 지침에 따라 개발 및 변경 사항이 발생할 때마다 본 현황 보고서를 수시로 작성 및 업데이트하여 개발 연속성과 코드 무결성을 지속 유지하겠습니다.
