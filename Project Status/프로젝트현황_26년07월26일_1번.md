## 2. Technical Stack (기술 스택)

- **라우팅**: React Router v7 (`react-router-dom ^7.9.6`) — `Suspense` + `lazy()` 기반 코드 스플리팅 적용 및 `AnonymousRoute` 가드를 통한 비로그인 사용자 전용 경로 보안 처리
- **상태 관리 & 데이터 페칭**:
  - 서버 상태: TanStack Query v5 (`@tanstack/react-query ^5.90.11`) — `keepPreviousData` (placeholderData) 적용으로 줌 조절 및 페이지 전환 시 깜빡임 방지

  - 애니메이션: Framer Motion (`^12.23.25`)

## 5. 핵심 도메인 및 필수 준수 수칙 현황

### 1) 데브스펙트럼 결과페이지 레이아웃 및 캡처 수칙 (필수 준수)
* PDF 저장 및 이미지 복사의 대상이 되는 모든 데브스펙트럼 결과페이지는 **`PrintPage` 기반 줌 투 핏(Zoom-to-Fit) 정비율 스케일링**, **수평 레이아웃 고정**, **SVG viewBox 기반 스케일링 조치**를 항상 필수로 적용해야 합니다.

### 2) DB 마이그레이션 수칙 준수
* 마이그레이션 실행 시 `npx node-pg-migrate`를 사용하며, 마이그레이션 파일은 **CommonJS (`exports.up = (pgm) => { ... }`)** 문법을 엄격히 준수합니다.
* GitHub Actions 배포 시 `npm run db:migrate`가 자동으로 수행되어 AWS 프로덕션 DB에 반영되므로 프로덕션 수동 마이그레이션 요청을 하지 않습니다.

### 3) 서브모듈 커밋 및 루트 저장소 포인터 커밋 수칙
* `frontend`, `backend`, `NewsMaker` 서브모듈 변경 시 서브모듈 커밋 즉시 메인 저장소(`AoID`)에서도 포인터 업데이트 커밋(`git commit -m "chore: update submodule pointer..."`)을 동시 수행합니다.

### 4) 서버 타임존 및 배포 수칙
* **서버 시간대**: `Asia/Seoul` (KST 기준)
* **Nginx 실제 설정 파일 위치**: EC2 프로덕션의 `/etc/nginx/sites-available/aoid`
* **자동 배포**: 배포는 GitHub Actions를 통해 자동 수행되며, `git push` 실행 전에 반드시 사용자 승인("푸시해도 될까요?")을 구합니다.
