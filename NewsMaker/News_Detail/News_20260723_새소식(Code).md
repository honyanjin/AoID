G. 기사본문
2026년 7월 23일, 사이버 보안 연구기관과 주요 외신들이 자율 AI 코딩 에이전트를 직접 타깃으로 삼는 신종 공급망 공격 기술인 'AgentBaiting'의 급증을 공식 경고했습니다.
AgentBaiting 공격은 공격자가 GitHub, npm, PyPI 및 Model Context Protocol(MCP) 마켓플레이스에 7,600개 이상의 가짜 오픈소스 리포지토리와 도구를 유포하는 방식으로 감행됩니다.
개발자가 AI 에이전트에게 특정 패키지 설치나 오픈소스 코드 수정을 지시할 때, 에이전트가 이 가짜 모듈을 정품으로 오인하여 자동으로 다운로드하고 실행하도록 유도합니다.
이 과정에서 SmartLoader 및 StealC와 같은 악성 탈취 프로그램이 호스트 시스템에 자동 설치됩니다.

이번 공격의 심각성은 전통적인 인간 개발자가 아닌 'AI 에이전트의 자동화된 판단 특성'을 악용한다는 점에 있습니다.
AI 에이전트는 코드 조작 및 패키지 설치 시 보안 인증 절차를 건너뛰거나 프롬프트 조작(Prompt Injection)에 속아 악성 스크립트에 포함된 명령어들을 그대로 실행하는 취약점을 지니고 있습니다.
한 사이버 보안 전문가는 "AI 개발 도구가 널리 보급되면서 이제 해커들이 사람의 클릭 대신 AI 에이전트를 속여 시스템 쉘 권한을 탈취하는 시대로 접어들었다"며 각별한 주의를 당부했습니다.
실제로 주요 IT 기업들의 개발 서버가 이 같은 방식으로 무단 침투를 당한 사례가 포착되었습니다.

전문가들은 에이전트가 외부 오픈소스를 자동으로 다운로드하고 빌드할 때 반드시 엄격한 샌드박스 격리 환경과 의존성 검증 도구를 강제해야 한다고 강조하고 있습니다.
GitHub과 주요 보안 업체들은 7월 23일 자로 관련 악성 리포지토리 대량 삭제 조치에 나섰으며, 에이전트용 보안 필터 알고리즘을 배포하기 시작했습니다.

JetBrains가 2026년 7월 22~23일 자사의 대표 C# 및 크로스 플랫폼 개발 IDE인 'Rider 2026.2'를 공식 정식 출시했습니다.

이제 Rider 2026.2 환경에서는 AI가 IDE가 파악한 완성형 구문 트리와 종속성 그래프를 즉시 전달받아 한 차원 높은 정밀도로 코드를 수정합니다.

또한 Rider 2026.2는 디버거 실행 속도를 2.8초 가량 대폭 단축시켰으며, Roslyn 아키텍처 개선을 통해 브랜치 전환 속도를 기존 대비 2~3배 이상 향상시켰습니다.
언리얼 엔진(Unreal Engine) 및 고도(Godot) 엔진 게임 개발자들을 위한 전용 시각화 툴과 C++ 인덱싱 성능 개선이 대거 이뤄졌습니다.
.NET 및 게임 개발 커뮤니티의 한 유저는 "AI 에이전트가 내가 지시한 고도 스크립트 작성 과제를 IDE 콘텍스트를 기반으로 단 한 번의 오차 없이 깔끔하게 반영하는 것을 보고 감탄했다"고 사용기를 남겼습니다.

JetBrains는 이번 Rider 2026.2 릴리즈를 필두로 자사 전 제품군에 에이전트 전용 컨텍스트 개방 아키텍처를 순차 도입할 계획입니다.

G. 기사본문
아마존웹서비스(AWS)가 2026년 7월 23일 자사의 클라우드 개발 자율 에이전트인 'Amazon Q Developer'의 최신 기능 업데이트를 발표했습니다.
이번 업데이트의 핵심은 소프트웨어 품질 관리를 위한 '자동 단위 테스트 생성' 및 '테스트 주도 개발(TDD) 자율 에이전트' 모듈의 대폭 강화입니다.
Amazon Q Developer는 프로젝트의 소스 코드를 스캐닝하여 테스트 커버리지가 낮은 모듈을 능동적으로 식별합니다.
이후 에지 케이스(Edge Case)와 예외 상황을 검증하는 모의 객체(Mock) 및 단위 테스트 코드를 스스로 작성하여 전체 품질 지표를 끌어올립니다.

특히 개발자가 함수 인터페이스만 작성해 놓으면, Amazon Q가 실패하는 테스트 코드를 먼저 작성한 뒤 이를 통과시키는 구현 코드를 연달아 작성하는 '자율 TDD 워크플로우'를 선사합니다.
이를 통해 개발자들이 가장 귀찮아하던 단위 테스트 작성 공수를 80% 이상 절감하면서도, 프로덕션 배포 전 코드의 안정성을 비약적으로 높일 수 있게 되었습니다.
QA 엔지니어링 커뮤니티의 한 전문가는 "단순히 예제 코드를 생성하는 수준이 아니라 실제 통합 테스트 규격을 만족하는 테스트 슈트를 완전 자동 생성하는 수준에 도달했다"고 높이 평가했습니다.

Amazon Q Developer는 IDE 환경에서 즉시 업데이트를 받아 사용할 수 있습니다.
