A. 타이틀
B. 부제
C. 중요도 (별1 ~10까지)
D. 이 뉴스가 어느 카테고리에 속하는지(IT일반, AI, Code 등등....)
E. 뉴스 내용에 해당되는 해시태그들
F. 각 뉴스마다 대표적으로 사용할 수 있는 연관 이미지 
G. 기사본문 
H. 뉴스를 작성한 자료들의 출처

[작성지침]
필수 작성 사항 순서에 맞게 내용을 작성할 것.
본문은 가능하면 1000자 정도로 작성할 것.
조사한 뉴스가 실제로 기간 내에 일어난 사건인지 반드시 면밀하게 재확인할 것.
이전에 일어난 일을 기간내에 다시 뉴스로 내보내는 사례를 주의할 것.
조사한 뉴스에 대해 실제로 자료조사를 실시하여 팩트를 면밀하게 체크할 것.
주요 AI 모델들의 업데이트, 개발자가 관심가질만한 뉴스로 선정할 것. 
답변 양식을 통일할 것.
뉴스 작성 자료들의 출처 주소들은 목록화하여 뉴스마다 하단에 정리해둘 것.
연관 이미지는 반드시 최소 3개는 찾아줄 것, 직접 그리라는 것이 아니라 연관된 이미지를 찾아서 표시.
태그들은 뉴스 본문의 내용을 잘 생각해서 태그들을 나열하고 그중에 대표적인 태그 1개를 골라서 대표 태그로 표시할 것. 
뉴스는 명확하게 [뉴스1] ~ [뉴스N]까지 명확하게 번호를 붙여 작성하고 뒤에 불필요하게 종합뉴스나 추가 양식으로 뉴스를 작성하지 말 것.
뉴스와 뉴스 사이에 구분선 넣어줄 것.
